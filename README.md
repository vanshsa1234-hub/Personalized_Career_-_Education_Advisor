# Personalized Career & Education Advisor

A web application that helps students and professionals discover personalized career paths, educational resources, and institutions based on their aptitude and interests.

---

## 🎯 Features

- Aptitude test to assess your strengths and weaknesses (`aptitude.html`)  
- Detailed career suggestions based on test results (`detailed_analysis.html`)  
- Browse colleges and educational institutions (`colleges.html`)  
- Chatbot feature to ask guidance-related questions (`chatbot.html`)  
- Resource directory for learning materials, articles, etc. (`resources.html`)  
- FAQs, contact support, feedback form  
- User registration & login, profile management  

---

## 🛠 Tech Stack

- **Frontend**: HTML, CSS, JavaScript  
- **Backend**: Node.js (via `server.js`)  
- **Dependencies**: As listed in `package.json`  
- **Static Assets / Pages**: multiple HTML pages (index, careers, contact, etc.)  
- **Style**: `style.css` for styling
